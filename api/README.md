# GitStats Backend
---
Backend for gitstats

## Vercel Serverless Deployment
This API is now structured for deployment as a Vercel serverless function. Do not use pm2 or nodemon to start the server. The Express app is exported as a module for Vercel compatibility.

## Run dev server 
> ``` 
> $ yarn / npm install 
> $ yarn run dev / npm run dev
> 

## Run production server
> ``` 
> $ yarn / npm install 
> $ yarn run start / npm run start
>
